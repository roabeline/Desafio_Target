# Exercícios de Lógica e Programação em Python

Este repositório reúne uma coleção de exercícios desenvolvidos em **Python**, com foco em **lógica de programação**, **resolução de problemas** e **conceitos fundamentais da linguagem**.  
Os códigos foram implementados e testados no ambiente **Google Colab**, simulando desafios comuns encontrados em **testes técnicos para estágios e vagas júnior**.

---

## 📌 Conteúdo do Repositório

### 1️⃣ Soma Sequencial com Laço de Repetição
Implementação de um algoritmo que realiza a soma dos números de `1` até um valor definido, utilizando a estrutura de repetição `while`.

**Conceitos abordados:**
- Variáveis
- Laço `while`
- Controle de fluxo
- Lógica matemática

---

### 2️⃣ Verificação de Número na Sequência de Fibonacci
Criação de funções para:
- Gerar a sequência de Fibonacci até um determinado limite
- Verificar se um número informado pelo usuário pertence à sequência

**Conceitos abordados:**
- Funções
- Listas
- Estruturas condicionais
- Entrada de dados (`input`)
- Lógica matemática

---

### 3️⃣ Análise de Faturamento a partir de Arquivo JSON
Leitura de um arquivo JSON contendo dados diários de faturamento, desconsiderando dias sem faturamento, para calcular:
- Menor valor de faturamento
- Maior valor de faturamento
- Média mensal
- Quantidade de dias com faturamento acima da média

O código inclui **tratamento de exceções** para lidar com erros de leitura e formatação do arquivo.

**Conceitos abordados:**
- Leitura de arquivos JSON
- Manipulação de dados
- List comprehensions
- Tratamento de exceções (`try/except`)
- Análise básica de dados

---

### 4️⃣ Inversão Manual de String
Implementação de um algoritmo para inverter uma string **sem utilizar funções prontas da linguagem**, reforçando o entendimento de índices e laços de repetição.

**Conceitos abordados:**
- Manipulação de strings
- Laço `for`
- Índices
- Lógica de programação

---

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Google Colab**

- **Google Drive (para armazenamento de arquivos)**

## 🎯 Objetivo do Projeto
O objetivo deste repositório é:
- Consolidar fundamentos de Python
- Praticar lógica de programação
- Simular desafios técnicos comuns em processos seletivos
- Servir como material de estudo e portfólio inicial

---

## ▶️ Como Executar
1. Abra o projeto no **Google Colab**
2. Execute as células na ordem
3. Quando solicitado, insira os valores via teclado
4. Para o exercício de faturamento, certifique-se de que o arquivo `dados.json` esteja no seu Google Drive
